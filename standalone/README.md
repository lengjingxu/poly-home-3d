# 单文件 3D 户型

双击 home-floorplan.html 即可离线浏览；Three.js 和交互代码全部内嵌，无外部请求，需要支持 WebGL 的浏览器。

拖动旋转、滚轮缩放、右键平移；支持俯视、房间点选、家具名称、墙体/家具/标签开关，以及当前视角 PNG 导出。

按本次用户提供的户型图重建：图纸坐标 (264,282) 为参考原点，84.4 像素对应 1 米；横向轴线尺寸链为 3400 / 2900 / 2300 / 3900 mm。家具按彩色标注和灰色轮廓定位；有明确尺寸的次卧床、衣柜、洗衣机按标注建模。墙高采用 1.15 米剖切，未提供的高度、材质、家具造型为示意。像素定位有读图误差，不能用于施工。图纸上方不代表已确认的地理北方。未连接 HA 或设备数据。

构建：在仓库根目录执行 node standalone/build.mjs。scene.js 是几何和交互源文件，shell.html 是页面模板。此模型独立于现有 HA 卡片，不修改其配置。

验证：Chrome file:// 离线打开、立体/俯视截图、房间点选、三项显示开关、PNG 数据生成、390px 移动端布局；运行中外部资源请求为 0。
衣帽间与主卧打通，书房与客厅打通；这两处不设隔墙和门扇。
