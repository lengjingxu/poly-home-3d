# 单文件 3D 户型

双击 home-floorplan.html 离线浏览。Three.js、材质纹理和交互全部内嵌，无外部资源请求，需要支持 WebGL 2 的浏览器。

拖动旋转、滚轮缩放、右键平移；支持俯视、房间/家具点选、三个材质近景、墙体/家具/标签显隐、完整墙高及 PNG 导出。导出包含光影后处理，不含 HTML 控件与标签。静止时停止重绘，操作视角或显隐后更新。

## 户型与用户确认

图纸坐标 (264,282) 为参考原点，84.4 像素对应 1 米；横向轴线链为 3400 / 2900 / 2300 / 3900 mm。图纸上方不代表地理北方。像素定位存在误差，不能用于施工；未连接 HA 或真实设备。

衣帽间与主卧、书房与客厅均打通，没有隔墙；模型省略所有房门。书房采用悬空白柜，次卧采用木纹柜与墙板，榻榻米平台两侧通墙。

客厅地面按用户确认改为灰色，无木纹；蓝色地毯保留。

包豪斯内装：黑色柜体和零食柜、凸出银色餐边柜、黑皮金属框 LC3 示意沙发、蓝色地毯、衣帽间黑柜银镜、玄关银色镜面墙。餐边柜沿用图中餐厅右侧展示柜位置。

高柜统一到顶，层高暂定 2.6 m；书房悬空柜上沿同高，下方留空暂按 1.45 m。操作台、岛台、飘窗柜和餐边低柜保留功能高度。墙体默认 1.15 m 剖切，可切到完整高度。LC3 造型比例、未标注高度和细节均为示意。

## 光影与材质

- PBR 材质、家具倒角与柜门实物分缝；皮革滚边、陶瓷台盆内凹、弯管龙头与洗衣机舱门细节。
- 程序生成木纹、错缝木地板、皮革毛孔、织物编织和拉丝金属纹理；床品有几何褶皱。
- SSAO 接触阴影、方向光阴影、环境反射、统一色调映射；视口与 PNG 使用相同渲染流程。
- 三块镜面随视角实时反射；不计算镜面之间的多次反射，非光线追踪渲染。

构建：仓库根目录运行 node standalone/build.mjs。scene.js 定义场景与交互，textures.js 生成确定性纹理，shell.html 为页面模板。此交付独立于现有 HA 卡片。

验证：Chrome file:// 加载与截图；近景、显隐、完整墙高、resize 和 PNG 生成；静止期间 renderCount 不增长；外部资源请求为 0；移动端布局；git diff --check。

## 实时灯光与镜头

默认黄昏；支持日间/黄昏/夜间三种艺术化光照预设、室内照明开关和曝光调节。六盏局部聚光灯中三盏投射阴影，柜下及餐桌面光源/发光灯带补充室内照明，Bloom 位于 SSAO 后、输出处理前。阴影图仅在光照、显隐或墙高改变后更新，静止场景停止重绘。灯位属于效果预览，未按真实灯具测绘，也不连接 HA。

近景和房间切换采用可打断的镜头过渡，支持手动镜头巡游、全屏。进入室内后，显示完整墙高与顶面，并切到 1.65 m 视线高度；点击立体返回全屋。它是可环顾的观察镜头，没有角色碰撞或自由行走系统。系统开启减少动态效果时，镜头直接切换。

快捷键：1/2/3 切换日间/黄昏/夜间，R 返回全屋。PNG 使用同一条包含辉光的输出流程。环境反射为摄影棚环境贴图配合预设强度调整，日夜效果不代表物理天空模拟或光线追踪。
